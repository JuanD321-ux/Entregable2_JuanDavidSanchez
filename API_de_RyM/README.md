# API de Rick y Morty 

Proyecto académico desarrollado en React para consumir la API pública de Rick and Morty.

## Funcionalidades

- Consulta de personajes desde la API.
- Visualización en tarjetas.
- Buscador por nombre.
- Filtro por especie.
- Navegación con React Router.
- Detalle individual de personajes.
- Manejo básico de carga y errores.
- Diseño responsive.

## Tecnologías

- React
- Vite
- JavaScript ES6+
- React Router DOM
- CSS
- Fetch API

## Instalación

```bash
npm install
npm run dev
```

Luego abre la URL que muestra la terminal, normalmente:

```txt
http://localhost:5173/
```
